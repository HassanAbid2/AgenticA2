# Realtime notes app

## Context
The brief from this productivity company was simple to say and hard to do: a shared notes app where edits show up instantly for everyone. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using TypeScript. Under the hood it relies on hosted Postgres with auth and realtime channels. Under the hood it relies on a React framework with server rendering and file routes. Under the hood it relies on a relational database with strong constraints. I wrote tests for the critical paths and documented the handover.

## Results
The system shipped MVP in 3 weeks; 2,300 weekly active users.
