# GraphQL API for a media app

## Context
This engagement (media) started with a pain point - a faster API for our video app; the mobile team needs flexible queries. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using GraphQL, TypeScript, Jest. Under the hood it relies on server-side JavaScript. Under the hood it relies on a document database. I wrote tests for the critical paths and documented the handover.

## Results
The system p95 API latency from 900ms to 140ms.
