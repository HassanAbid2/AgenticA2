# Lessons from building SpeedUp

*Posted 2025-08*

Last year I spent a few months on SpeedUp, a project for a marketing team. The ask: make our marketing site load fast and look modern. Honestly the hardest part wasn't the model or the code, it was getting clean inputs. We ended up using Vercel and React, plus a React framework with server rendering and file routes. End result: it Lighthouse score 54 to 98; paid-ad conversion up 9%.

What I'd do differently: start with evaluation earlier.
