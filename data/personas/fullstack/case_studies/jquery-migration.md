# Legacy jQuery to React migration

## Context
The brief from this insurance company was simple to say and hard to do: replace our old quote form front end without breaking anything. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using React, TypeScript, JavaScript. Under the hood it relies on JavaScript unit tests with mocks. I wrote tests for the critical paths and documented the handover.

## Results
The system bundle size down 60%; zero downtime across a 4-month migration.
