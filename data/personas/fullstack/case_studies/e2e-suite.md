# End-to-end test suite and CI

## Context
A SaaS client came to me needing automated tests so releases stop breaking the signup flow. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using Playwright, Jest, CI/CD, TypeScript, Docker.  I wrote tests for the critical paths and documented the handover.

## Results
The system escaped bugs per release down from 7 to 1.
