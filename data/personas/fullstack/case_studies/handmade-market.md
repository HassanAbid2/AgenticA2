# Marketplace for handmade goods

## Context
This engagement (e-commerce) started with a pain point - an online marketplace where makers can list products and get paid. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using Next.js, Supabase, Tailwind CSS, TypeScript. Under the hood it relies on card payments, subscriptions and billing webhooks. I wrote tests for the critical paths and documented the handover.

## Results
The system launched with 340 sellers; checkout conversion 3.9%.

## Stack
- Next.js
- Supabase
- Tailwind CSS
- TypeScript
