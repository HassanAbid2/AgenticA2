# A/B test readout framework

## Context
This engagement (e-commerce) started with a pain point - a consistent way to analyse our website experiments. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using A/B testing, Python, R. Under the hood it relies on hypothesis tests, confidence intervals and regression. I wrote tests for the critical paths and documented the handover.

## Results
The system standardised 40+ experiment readouts with power checks.
