# Warehouse refactor with dbt

## Context
The brief from this SaaS company was simple to say and hard to do: clean up our data warehouse so metrics stop disagreeing between reports. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using dbt, Snowflake, SQL.  I wrote tests for the critical paths and documented the handover.

## Results
The system dashboard query time down 70%; 140 models with tests.
