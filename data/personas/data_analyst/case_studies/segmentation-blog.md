# Lessons from building SegmentIQ

*Posted 2023-09*

Last year I spent a few months on SegmentIQ, a project for a e-commerce team. The ask: group our customers so marketing can target them differently. Honestly the hardest part wasn't the model or the code, it was getting clean inputs. We ended up using Python and clustering and pandas. End result: it 5 segments drove a targeted email that lifted revenue per send 23%.

What I'd do differently: start with evaluation earlier.
