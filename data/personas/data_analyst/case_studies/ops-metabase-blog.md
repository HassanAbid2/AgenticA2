# Lessons from building OpsBoard

*Posted 2022-05*

Last year I spent a few months on OpsBoard, a project for a logistics team. The ask: simple self-serve dashboards for our warehouse managers. Honestly the hardest part wasn't the model or the code, it was getting clean inputs. We ended up using Metabase and PostgreSQL and SQL. End result: it warehouse leads check 12 live KPIs instead of asking analysts.

What I'd do differently: start with evaluation earlier.
