# Product recommendation engine

## Context
This engagement (e-commerce) started with a pain point - "customers also bought" suggestions that actually reflect what each shopper likes. They had tried an off-the-shelf tool first and it did not fit their workflow.

## What I built
I designed and shipped the solution end to end using Python, recommendation systems, Redis, FastAPI. Under the hood it relies on a dynamic-graph deep learning framework from Meta. I wrote tests for the critical paths and documented the handover.

## Results
The system click-through up 14% in a four-week A/B test.
